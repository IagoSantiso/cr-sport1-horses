# CR Sport Horses — demo navegable

Demo estática del diseño de Stitch (5 pantallas). Sin build ni dependencias: abre `index.html` directamente o sirve la carpeta con cualquier servidor estático (`npx http-server .`).

| Archivo | Pantalla |
|---|---|
| `index.html` | Inicio |
| `catalogo.html` | Caballos en venta (filtros funcionales + formulario "Encargo a medida") |
| `ficha-cornet-d-or.html` | Ficha de caballo (galería + formulario de visita) |
| `entrenamiento.html` | Entrenamiento y tecnificación |
| `pupilaje.html` | Pupilaje deportivo |

`El Centro`, `Roi Calviño` y `Escuela`/`Contacto` apuntan a secciones de las pantallas existentes; las fichas de otros caballos y las páginas legales muestran un aviso ("solo en la versión final").

`assets/` contiene Tailwind (v3.4.17, runtime), fuentes e imágenes en local, de modo que funciona sin conexión.
Los datos de contacto (`+34 600 123 456`, `info@crsportshorses.com`) son de ejemplo.
